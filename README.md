I build web apps end to end and I'm growing a portfolio of projects that don't all look the same.

These days I'm mostly sharpening the front end: layout, motion, and interfaces people actually enjoy using. If that's your thing, I'd like to learn from you, and I'm happy to pitch in on open-source web projects.

Ask me about responsive design, APIs, databases, or taking an app from an empty folder to production.
